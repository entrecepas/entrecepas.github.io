Para docentes

Guía didáctica

Una guía de una o dos páginas por tema, lista para usar en el aula con los retos de la web.

Cómo usar las guías

Cada guía propone una secuencia de antes, jugar y después, vocabulario, preguntas para el debate y criterios para evaluar. Está pensada para 3.º–4.º de ESO y Bachillerato y se puede adaptar a otros niveles. Todas las cifras proceden de las investigaciones citadas en cada guía.

Son PDF etiquetados, con título e idioma, para que se puedan leer con lector de pantalla. Se pueden copiar, adaptar y compartir (CC BY 4.0), citando la autoría.

    Dentro de una misma parcela el suelo y las cepas cambian mucho; la viticultura de precisión mide esas diferencias para actuar donde hace falta.

    Materias: Biología y Geología · Tecnología y Digitalización · Geografía · Duración: 50 min

    Descargar PDF de «Viticultura de precisión: cada cepa cuenta»

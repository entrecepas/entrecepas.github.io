# Fotos de las comparativas (opcional)

1. Guarda cada foto en `img/comparativas/` con el nombre de la columna `archivo` de `data/comparativas_creditos.csv` (por ejemplo `burj-khalifa.jpg`, unos 900 px de ancho).
2. Rellena en esa misma fila `descripcion_alt`, `autor`, `licencia` y `url_fuente` (p. ej. Wikimedia Commons, con su licencia CC).
3. Ejecuta `python3 tools/build.py`: solo salen las fotos con archivo y crédito completos (autor y descripción).
